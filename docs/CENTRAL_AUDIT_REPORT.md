## 3. التوصيات النهائية قبل تفعيل المزامنة السحابية الحقيقية (Roadmap Next Steps)

1. **الاستمرار على قاعدة Dexie المحلية**: الإبقاء على `CashierPro_DB` مصدراً وحيداً للتشغيل المحلي (`operationalSource = 'dexie'`).
2. **عدم تفعيل Firebase إلا بطلب صريح**: تفعيل السحابة يتطلب بدء موافقة `set_up_firebase` / `ProvisionFirebase` رسمياً.
3. **تطبيق سياسة الترقية الآمنة للمتجر**: تطبيق إعدادات المشرف ورموز PIN عبر واجهة المستخدم المعتمدة.
